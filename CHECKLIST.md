# Checklist del proyecto

Este documento se completa progresivamente durante el desarrollo del proyecto.

## Fase 1: infraestructura
- [ ] README inicial con descripción del proyecto.
- [ ] Repositorio con estructura base y archivos de arranque.
- [ ] Makefile y gitignore iniciales.

## Fase 2: C++ y trazas
- [ ] Parser de grafos a partir de archivos en `data/*.txt`.
- [ ] Algoritmo de Tarjan real en C++.
- [ ] Emisión de eventos JSONL por stdout.
- [ ] Tests unitarios para grafos base.

## Fase 3: Manim
- [ ] Lector de trazas.
- [ ] Vista reutilizable del grafo.
- [ ] Escenas del storyboard.
- [ ] Render por sección y concat final.

## Fase 4: validación final
- [ ] Duración final dentro del rango requerido.
- [ ] `make all` produce `out/final.mp4`.
- [ ] README y checklist completos.
